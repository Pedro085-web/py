⚔️ RPG — O Chamado

Projeto experimental de RPG desenvolvido em Python para praticar programação através de uma narrativa interativa.

O jogador informa seu nome, possui uma classe e acompanha uma história através de diálogos e escolhas.

Conceitos utilizados:

print()
input()
Variáveis
if / elif / else
Escolhas do jogador
Pausas entre diálogos
Estrutura de narrativa
Sistema inicial de personagem

Elementos atuais:

Classe Guerreiro
HP

Personagem Lyra
Diálogos interativos
Sistema de escolhas
Diferentes respostas para cada escolha
